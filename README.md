# 臼井和真 · 个人主页

一个纯静态的个人简介网页，无需任何构建工具、框架或外部 CDN 依赖，双击 `index.html` 即可打开，
也可直接上传到 GitHub 通过 Pages 发布。

## 目录结构

```
personal-profile/
├── index.html              # 页面结构与全部文字内容（改内容主要改这里）
├── assets/
│   ├── css/style.css       # 样式表，含设计变量、占位标记样式与响应式断点
│   ├── js/main.js          # 交互脚本（导航、滚动动画、主题切换、复制邮箱）
│   └── img/
│       ├── favicon.svg     # 浏览器标签页图标
│       └── avatar.jpg      # 你的照片（需要自己放进这个目录）
└── README.md
```

## 还没填、留了占位的地方

占位统一用灰色虚线标记（文字是 `待补充`，链接是带虚线下划线且点不动），
在 `index.html` 里搜索 `待补充` 就能一次找全，一共这几处：

| 位置 | 现在的样子 | 怎么改 |
| --- | --- | --- |
| 首页简介 | 正在学 `<span class="tbd">待补充</span>` | 换成你正在学的技术，例如「Java」，然后把 `<span class="tbd">…</span>` 整段删掉 |
| 项目卡片标题 | `项目名 <span class="tbd">待补充</span>` | 换成项目名 |
| 项目卡片时间 | `待补充` | 换成项目起止时间 |
| 项目描述 | 一段说明文字 | 换成「解决了什么问题 + 可验证的结果」 |
| 项目技术标签 | `<li>技术待补充</li>` | 换成用到的技术，可写多个 `<li>` |
| 项目代码链接 | `<a href="#" class="is-tbd">` | `href` 换成仓库地址，并删掉 `class="is-tbd"`、`aria-disabled`、`tabindex` |
| 学习输出链接 | `<a href="#" class="is-tbd">链接待补充</a>` | 同上，换成博客 / 笔记地址并去掉占位标记 |

每个占位上方都有一段 `<!-- TODO: ... -->` 注释说明怎么替换，照着改就行。

## 书单 / 音游清单怎么维护

都在 `index.html` 的「个人兴趣」板块里，纯清单结构，加一行就行：

```html
<!-- 加一本书（带分类小标签） -->
<li><span class="book-tag">分类</span><span class="book-name">《书名》</span></li>

<!-- 加一本书（不带标签） -->
<li><span class="book-name">《书名》</span></li>

<!-- 加一款音游 -->
<li>游戏名</li>
```

书单在宽屏会自动排成两列、窄屏收成一列，不用手动调排版。

## 其他要你补的内容

- **照片**：存成 `assets/img/avatar.jpg` 放进 `assets/img/`。正方形、不小于 400×400、人物居中。
  文件不存在时会自动回退显示姓名首字「臼」，不会破图。
- **高中时间**：现写作 `2022.09 – 2025.06`，如与实际不符请自行修改。
- **毕业时间**：现写作 `2029.06`（按四年制推算），如有出入请修改。
- **简历按钮**：需要的话把简历放到 `assets/resume.pdf`，再启用 `index.html` 首页里注释掉的那行「下载简历」按钮。
- **主题色**：改 `assets/css/style.css` 顶部 `:root` 里的 `--primary`、`--accent`，全站配色自动跟随。

## 本地预览

直接双击 `index.html`，或在项目目录下起一个本地服务（推荐，可避免个别浏览器对本地文件的限制）：

```bash
# Python 3
python -m http.server 8000

# 或者 Node.js
npx serve .
```

然后访问 http://localhost:8000

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `my-profile`。
2. 把本目录内容推送到仓库（`index.html` 需位于仓库根目录）：

```bash
git init
git add .
git commit -m "feat: 个人主页"
git branch -M main
git remote add origin https://github.com/你的用户名/my-profile.git
git push -u origin main
```

3. 打开仓库 **Settings → Pages**，Source 选择 `Deploy from a branch`，
   Branch 选 `main` + `/ (root)`，保存。
4. 等待 1 分钟左右，访问 `https://你的用户名.github.io/my-profile/` 即可看到页面。

> 提示：若把仓库命名为 `你的用户名.github.io`，发布地址直接就是 `https://你的用户名.github.io/`。

## 设计与技术说明

- **响应式**：三档断点（960px / 820px / 480px）。820px 以下导航折叠为下拉菜单，首页改为纵向排列，
  网格降为单列；网格用 `minmax(min(300px, 100%), 1fr)` 写法，极窄屏幕也不会溢出。
- **主题**：内置浅色 / 深色两套配色，右上角按钮切换并记忆到 `localStorage`，首次访问跟随系统偏好。
- **无外部依赖**：图标为内联 SVG，字体使用系统字体栈，离线可用，加载快。
- **渐进增强**：所有内容都写在 HTML 中，脚本只负责交互；即使禁用 JavaScript，页面依然完整可读。
- **可维护性**：CSS 按功能分区并带目录注释，颜色 / 圆角 / 间距集中在 `:root` 变量里；
  JS 用 IIFE 隔离作用域并按功能分节，改动互不影响。
- **无障碍**：语义化标签、跳转链接、`aria` 属性、键盘焦点样式，并适配 `prefers-reduced-motion`。
- **打印友好**：直接 Ctrl/Cmd + P 可导出为干净的 PDF（自动隐藏导航与按钮）。
